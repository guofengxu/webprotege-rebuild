# ADR-009 搜索：嵌入式 Lucene 10，派生且可重建

- 状态：已接受
- 日期：2026-10-28

## 决策
- 每个项目一个 Lucene 索引目录（`${wp.data-dir}/search/<projectId>`），索引实体 IRI、本地名、各语言的显示名称。
- 索引是派生数据：启动或发现索引的修订号落后于 head 时，从 `ProjectRuntime` 重建。
- 增量更新在 PostCommit 监听器中执行；索引里记录已处理的修订号，允许最多落后几个修订（最终一致）。

## 理由
旧系统同样用 Lucene 做短名搜索，需求已验证；嵌入式部署不增加运维组件。
