# ADR-012 MVP 范围

- 状态：已接受
- 日期：2026-10-28
- 修订：2026-10-29 —— 增加移动端 MVP（M5），扩展功能顺延到 P6。

MVP = 里程碑 M4（Web 端）+ M5（移动端）。完整清单见 `docs/03-plan/mvp-scope.md`。

## 决策
- **Web 端 MVP（M4）**：账户与登录、项目管理、上传导入与下载导出、类 / 属性 / 个体的层级浏览与创建删除、实体 Frame 查看与编辑、搜索、修订历史与回滚、权限、实时事件、旧数据迁移。
- **移动端 MVP（M5）**：以**查阅和跟踪**为主——登录、项目列表、层级浏览、实体详情（只读）、搜索、修订历史、变更提醒；编辑只开放标签与注解这类轻量修改。完整的本体建模仍在 Web 端完成。
- **暂不纳入**（P6）：表单（Forms）、讨论与评论、关注（Watches）、标签、webhook、可视化、合并实体、批量操作、CSV 导入、OBO 专有功能、Manchester 语法编辑器、OIDC、实例库、本体发布到图数据库 / Kafka、MCP 工具。

## 理由
- 旧系统演进证据显示，表单是后期扩张最快的子系统，复杂度高；先交付核心编辑闭环，再按真实需求排序扩展功能。
- 在手机上编辑公理、类表达式的体验很差，移动端的价值在于现场查阅与跟踪变更。
