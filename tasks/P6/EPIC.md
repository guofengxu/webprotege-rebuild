# P6 扩展功能：候选清单

由人在“优先级”列填写 1（最高）~ 3 或“不做”，然后执行 `P6-00`。

| 候选项 | 说明 | 优先级 |
|---|---|---|
| 实例库服务 PoC | ADR-013：独立的 PostgreSQL 18 数据库（`wp_instances`），`instances` + `links` 模型，由本体生成校验规则；用诺和诺德仓库的规模造数据，测量深层追溯查询；p95 达不到 1 秒时评估 Apache AGE | |
| 本体投影表 | ADR-013：由 outbox 驱动、只读、可重建的实体 / 标签 / 父子关系 / 定义域与值域表，供 BI 与 AI Agent 用 SQL 查询 | |
| outbox 发布器 → 图数据库 | 把每个修订同步到图数据库（Neo4j + neosemantics 或 RDF 三元组库），供 AI Agent 运行时查询 | |
| outbox 发布器 → Kafka | 把修订事件发布到 Kafka 主题，供其它系统订阅 | |
| MCP 工具 | 把只读查询命令（层级、Frame、搜索、历史）暴露为 MCP 工具；写操作需要人工确认 | |
| 移动端：iOS 与微信小程序 | ADR-014 首期之外的平台；小程序需要合法域名与 HTTPS | |
| 移动端推送通知 | 关注的实体被修改时推送 | |
| Vue 3.6 升级 | 3.6 正式发布后升级 Web 端，单独一张卡 | |
| TypeScript 7 评估 | vue-tsc 正式支持后再评估 | |
| 表单（Forms） | 旧系统后期扩张最快的子系统，复杂度高，建议单独做逆向分析后再拆卡 | |
| 讨论与评论 | 实体级讨论线程 | |
| 关注（Watches）与通知 | 关注实体、邮件通知 | |
| 标签 | 项目标签、实体打标签 | |
| webhook | 修订提交后回调外部 URL（可以基于 outbox 实现） | |
| 合并实体 | 把实体 A 合并到 B，并替换全部引用 | |
| 上传并合并到已有项目 | 对应旧系统的 `merge_add` | |
| Manchester 语法编辑 | 类 Frame 的高级编辑方式 | |
| OIDC / 企业微信登录 | 接入企业身份提供方 | |
| 多实例部署 | 按项目把请求路由到加载了该项目的实例 | |
| 删除用户 | 需要先确定其历史修订如何展示 | |
